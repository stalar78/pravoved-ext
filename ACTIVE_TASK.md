# ACTIVE TASK

**v0.1-F2 — Complete Answer Threads**

Цель этапа — при копировании карточки Pravoved не терять последующие сообщения,
опубликованные внутри ветки конкретного ответа.

Ранее structured extractor сохранял:

- основной ответ юриста;
- только последующие сообщения исходного клиента.

Из-за этого продолжение самого юриста в той же ветке не попадало в
`Скопировать для ChatGPT`.

## Source

Используются только явные вложенные контейнеры конкретного answer:

- `comments`;
- `replies`;
- `messages`;
- `discussion`;
- `clarifications`;
- `followUps` / `followups`.

Полный Redux state рекурсивно не сканируется.

## Role classification

Каждое дополнение получает role:

- `CLIENT` — автор совпадает с автором исходного вопроса;
- `LAWYER` — автор совпадает с автором основного ответа либо явно имеет lawyer/expert role;
- `UNKNOWN` — текст сохраняется, но роль не угадывается.

ID пользователя имеет приоритет над совпадением имени.

## Data model

У answer появляется:

`followUps: [{ id, role, author, publishedAt, text, source }]`

Для обратной совместимости сохраняется:

`clientFollowUps`

как subset `followUps` с role `CLIENT`.

Основное `answersCount` не меняется: продолжения внутри ветки не считаются отдельными
ответами юристов.

## Copy output

После основного ответа при наличии продолжений выводится:

`ДОПОЛНЕНИЯ В ВЕТКЕ ЭТОГО ОТВЕТА:`

Каждая реплика маркируется:

- `ЮРИСТ`;
- `КЛИЕНТ`;
- `НЕ ОПРЕДЕЛЕНО`.

`https://pravoved.ru/question/5075795/`

`Количество ответов: 5`

При этом в ветке Хитцова должен дополнительно копироваться текст, начинающийся:

`Чтобы подробно Вас проконсультировать нужно видеть Ваш договор.`

В ветке Нежемединова должен дополнительно копироваться текст, начинающийся:

`Остальное можно пояснить только изучив ваш договор.`

Также повторно проверить ранее пройденный кейс с дополнением клиента: клиентские
уточнения должны продолжить копироваться с role `КЛИЕНТ`.
