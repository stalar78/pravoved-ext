# ACTIVE TASK

**v0.1-C2 — Adaptive ZIP Download**

Цель этапа — адаптивное скачивание вложений в зависимости от их количества.

## UX

Если вложений нет:

- download-кнопка скрыта.

Если вложение одно:

- кнопка `Скачать файл`;
- используется обычная загрузка одного файла через Chrome Downloads API.

Если вложений два и больше:

- кнопка `Скачать ZIP (N)`;
- все вложения текущего вопроса сначала локально загружаются расширением;
- формируется один архив `Pravoved-<question_id>.zip`;
- браузер получает только одну загрузку ZIP.

Это позволяет оставить включённой глобальную настройку Chrome
«Перед скачиванием спрашивать, куда сохранить файл» и подтверждать место только один раз.

## Архитектура

- single-file download остаётся через MV3 service worker и `chrome.downloads`;
- multi-file download выполняется в content-script модуле `src/download/zip.js`;
- ZIP собирается локально, без backend и сторонних библиотек;
- ZIP использует стандартный STORE method, UTF-8 filenames и CRC32;
- исходные вложения запрашиваются только по разрешённым URL Pravoved;
- никакие файлы не отправляются наружу.

## Acceptance target

Вопрос `5043426` с тремя PDF:

- кнопка показывает `Скачать ZIP (3)`;
- по нажатию появляется одна загрузка `Pravoved-5043426.zip`;
- Windows/Chrome спрашивает место сохранения только один раз;
- ZIP открывается стандартными средствами Windows;
- внутри ZIP три исходных PDF с корректными именами.

Дополнительно нужен вопрос с одним вложением:

- кнопка `Скачать файл`;
- файл скачивается обычным способом, без ZIP.
