# ACTIVE TASK

**v0.1-F1 — Paid Question Classification**

Цель этапа — явно различать обычные и платные вопросы Pravoved в панели расширения
и в тексте, который копируется для ChatGPT.

## Source

Primary structured source уже содержит:

`question.labels.isPaid`

Никаких эвристик по цене, тексту вопроса или DOM не используется.

Нормализация сохраняет tri-state:

- `true` -> платный вопрос;
- `false` -> обычный вопрос;
- `null` -> признак не найден / structured data недоступны.

## UI

Рядом с ID вопроса показывается badge:

- `ПЛАТНЫЙ`;
- `ОБЫЧНЫЙ`;
- `НЕ ОПРЕДЕЛЕНО`.

Рабочий status `SKIP / ANSWER / LEAD` пока сохраняется отдельной вторичной строкой,
чтобы не ломать существующее поведение.

## Copy output

В блок `=== PRAVOVED CASE ===` после ID добавляется:

`Тип вопроса:`

и одно из значений:

- `ПЛАТНЫЙ`;
- `ОБЫЧНЫЙ`;
- `НЕ ОПРЕДЕЛЕНО`.

Таким образом downstream-анализ сразу получает коммерчески значимый тип карточки
вместе с остальным контекстом.

## Acceptance target

Проверить одну обычную и одну платную карточку Pravoved:

- badge в панели соответствует типу карточки;
- `Скопировать для ChatGPT` содержит правильную строку `Тип вопроса`;
- вопрос, ответы, дополнения клиента и вложения продолжают копироваться без изменений.
