# ACTIVE TASK

**v0.1-E1 — Chat Typing Pulse**

Цель этапа — добавить в личные чаты Pravoved ручную имитацию набора текста,
чтобы собеседник видел обычный индикатор «печатает», пока юрист готовит ответ
в отдельном редакторе.

Работает только на страницах:

`https://pravoved.ru/private/chat/<chat_id>/`

## UX

В свободной области нижней панели чата добавляется кнопка:

`Имитировать набор`

После запуска:

`● Печатаю 1:59 · Стоп`

По умолчанию сеанс длится 2 минуты.

Повторное нажатие останавливает его вручную.

## Поведение

Typing Pulse запускается только при пустом редакторе сообщения.

Он автоматически останавливается, когда:

- пользователь реально начинает печатать;
- вставляет текст;
- перетаскивает текст в редактор;
- в поле появляется содержимое;
- сообщение отправлено;
- открыт другой чат;
- истекли 2 минуты.

Никакие сообщения автоматически не отправляются.

## Реализация

Добавлены:

- `src/chat/typing-page.js` — MAIN-world pulse engine;
- `src/chat/typing.js` — изолированный postMessage bridge;
- `src/ui/chat-typing-control.js` — компактный Shadow DOM control;
- `src/chat/typing-content.js` — lifecycle и route sync.

MAIN-world engine каждые ~2.4–4.2 секунды создаёт короткий Draft.js/input pulse:

1. фокусирует штатный contenteditable Pravoved;
2. отправляет keyboard pulse;
3. вставляет нулевой служебный символ через browser editing command;
4. через ~180 мс удаляет только этот символ;
5. повторяет цикл.

Если browser editing command недоступен, используется event-only fallback.

Служебный символ никогда не отправляется автоматически как сообщение.

## Безопасность поля

Pulse не стартует при непустом редакторе.

При удалении ищется и удаляется только собственный zero-width marker.
Если пользователь начал ввод между вставкой и удалением, содержимое пользователя
не очищается; lifecycle немедленно останавливает pulse.

## Browser acceptance target

Нужна проверка на реальном чате с доступом к стороне клиента:

- кнопка появляется в нижней панели и не мешает download-control;
- при пустом поле запускается `● Печатаю …`;
- на стороне клиента появляется штатный индикатор набора;
- поле сообщения визуально остаётся пустым между pulses;
- вставка готового текста автоматически выключает pulse;
- ручной набор автоматически выключает pulse;
- кнопка Stop работает;
- через 2 минуты pulse завершается сам;
- сообщение никогда не отправляется автоматически.
